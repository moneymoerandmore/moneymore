# Qlib 深度学习与因子策略 A/B 模拟

## 账户隔离

| 账户 | 策略 | 当前阶段 |
|---|---|---|
| `multi_sector_shadow` | MoneyMore 多行业因子模型 | 正式影子模拟 |
| `qlib_gru_shadow` | Qlib GRU 五随机种子集成 | 实验模拟 |

两个账户拥有独立资金、信号、订单、成交、持仓和对账记录。深度学习账户
的失败不会中断因子账户流水线，也不会进入 M4.14 因子模型验收证据。

## 活动深度学习策略

- 模型：`qlib_gru_alpha360_v1`；
- 输入：6类量价序列特征，每类60个交易日；
- 标签：未来5日收益减同行业同期平均收益；
- 训练：5个固定随机种子，预测时等权集成；
- 选股：每行业2只；
- 缓冲退出：行业排名跌出第4名才退出；
- 调仓：每5个交易日一次；
- 目标总仓位：40%；
- 执行：T日收盘信号、T+1开盘模拟撮合。

## 两级门槛

实验模拟门槛用于决定模型是否有资格产生独立模拟订单：

- 样本不少于10,000；
- Rank IC不低于0.01；
- Rank ICIR不低于0.08；
- 成本调整后Top-K超额为正；
- 至少5个随机种子；
- 至少80%的随机种子Rank IC为正。

正式晋级门槛保持更严格：

- Rank IC不低于0.02；
- Rank ICIR不低于0.10；
- 至少20个已成熟前瞻观察日；
- 前瞻Rank IC为正。

实验模拟不代表模型有效，也不代表可以接入真实券商账户。

## 当前研究结论

V1五种子全部获得正Rank IC，集成结果：

- Rank IC：0.01269；
- Rank ICIR：0.09252；
- 平均换手率：12.25%；
- 成本调整后Top-K超额：0.02827%。

V1通过实验模拟门槛，但未达到正式晋级门槛。

多尺度12特征V2也完成了同口径实验，但集成Rank IC为负，只有1/5种子为正，
因此被拒绝部署并保留为失败候选证据。

## 比较规则

前台“Qlib挑战者”页面同时展示：

- 两个账户的累计收益；
- 年化波动率；
- 夏普比率；
- 最大回撤；
- 观察交易日数量；
- GRU前瞻Rank IC和Top-K超额。

至少积累20个共同模拟交易日后，比较状态才变为可评价。在此之前只展示
事实数据，不给出“哪个策略更好”的结论。
